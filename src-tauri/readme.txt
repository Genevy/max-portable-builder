====================================================================
MAX Portable — портативная оболочка для веб-версии мессенджера MAX
====================================================================

О ПРИЛОЖЕНИИ
  Неофициальная портативная сборка (Pake/Tauri v2/WebView2) для личного
  использования. Открывает https://web.max.ru/ в отдельном окне.
  Готовые exe/msi не публикуются, исходный код открыт:
  https://github.com/Genevy/max-portable-builder

ЗАПУСК
  MaxPortable.exe. Вход по QR-коду или номеру телефона, как на сайте.
  Сессия и кэш хранятся в папке data\ рядом с exe. Пароль не сохраняется.

ТРЕБОВАНИЯ
  Windows 10/11 x64, WebView2 Runtime (обычно уже установлен).

УДАЛЕНИЕ (через командную строку)
  1. Закрыть приложение: taskkill /IM MaxPortable.exe /F
  2. Удалить папку с программой (вместе с data\ — там сессия и кэш).
  3. Удалить ярлык "MAX Portable" с рабочего стола.
  4. Удалить запись max:// из реестра:
     reg delete "HKCU\Software\Classes\max" /f

  ВНИМАНИЕ: На чужом компьютере после работы удалите папку с data\
  (сессия, кэш), ярлык и запись max:// в реестре.

ПРАВОВОЙ СТАТУС
  Неофициальная сборка. Не связана с VK/MAX. Начинка — веб-версия MAX,
  права принадлежат правообладателю. Только для личного использования.
